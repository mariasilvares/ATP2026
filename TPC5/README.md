**Resumo:** Neste trabalho, foi desenvolvida uma aplicação em Python para a gestão de uma turma de alunos, através de um menu de operações. Foram implementadas funcionalidades que permitiram criar uma turma com um número definido de alunos, inserir novos alunos, listar todos os alunos da turma e consultar um aluno através do seu ID. Cada aluno foi representado por um tuplo constituído pelo nome, pelo ID e por uma lista com três notas, correspondentes ao TPC, ao projeto e ao teste. Foi também implementada a possibilidade de guardar os dados da turma num ficheiro de texto e de carregar uma turma previamente guardada. Para o desenvolvimento da aplicação, foram utilizadas funções, listas, tuplos, variáveis, ciclos `while` e `for`, estruturas condicionais `if` e operações de leitura e escrita em ficheiros. Por fim, foi implementado um ciclo que permitiu apresentar novamente o menu após cada operação, até ser selecionada a opção de saída.
