**Resumo:** Neste trabalho foi desenvolvido, em Python, um jogo de adivinhação com duas modalidades. O utilizador começa por escolher a modalidade que pretende jogar. Na primeira modalidade, o computador gera aleatoriamente um número inteiro entre 0 e 100 e o utilizador tenta adivinhá-lo. O programa verifica cada tentativa, indica se o número pensado é maior ou menor e contabiliza o número de tentativas até o utilizador acertar. Na segunda modalidade, o utilizador escolhe um número entre 0 e 100 e o computador tenta adivinhá-lo. Através das respostas do utilizador, o programa vai ajustando o intervalo de números possíveis até encontrar o número escolhido, contabilizando também o número de tentativas. Para realizar o trabalho foram utilizados ciclos `while`, estruturas condicionais `if`, `elif` e `else`, entrada de dados através de `input()`, conversão para números inteiros, a biblioteca `random` para gerar números aleatórios e uma variável para contar as tentativas.
