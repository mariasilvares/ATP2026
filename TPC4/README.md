Neste TPC foi desenvolvida uma aplicação em Python que permitiu criar, ler e manipular listas de números inteiros através de um menu interativo. O programa foi organizado em funções e utilizou um ciclo while para apresentar repetidamente o menu até o utilizador selecionar a opção de saída.
Foi criada uma variável interna, listaatual, para guardar a lista em utilização. Através da opção 1, foi possível gerar uma lista com números aleatórios entre 1 e 100, enquanto a opção 2 permitiu introduzir números manualmente. Em ambos os casos, a nova lista substituiu a anterior.
Foram implementadas funções para calcular a soma, a média, o maior e o menor elemento da lista. Foi também desenvolvida uma função de pesquisa que devolveu a posição de um elemento, ou -1 caso este não existisse na lista.
O trabalho permitiu aplicar conceitos fundamentais de programação, nomeadamente listas, funções, ciclos while, estruturas condicionais (if, elif e else), índices e valores de retorno (return). Foi ainda trabalhada a manipulação de listas através de operações de ordenação.
Por fim, foi implementado o encerramento do programa através da opção 0, que apresentou uma mensagem de despedida.
