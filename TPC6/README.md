**Resumo:** Este TPC consiste num programa em Python desenvolvido para a gestão e análise de uma tabela meteorológica. A estrutura de dados principal armazena a informação sob a forma de tuplos com o formato (Data, TempMin, TempMax, Precipitacao). O script disponibiliza um menu interativo com várias funcionalidades de tratamento de dados, permitindo calcular a temperatura média diária (medias), guardar a tabela meteorológica num ficheiro de texto (guardaTabMeteo) e carregá-la de volta (carregaTabMeteo). Além disso, o programa consegue determinar a temperatura mínima mais baixa registada (minMin), calcular a amplitude térmica diária (amplTerm), identificar o dia com o valor máximo de precipitação (maxChuva), listar os dias em que a pluviosidade ultrapassou um determinado limite p (diasChuvosos), e calcular o maior número consecutivo de dias com precipitação abaixo de um limite p (maxPeriodoCalor). Por fim, o projeto integra a biblioteca matplotlib para gerar gráficos visuais correspondentes aos valores de temperatura máxima, mínima e pluviosidade (grafTabMeteo).
